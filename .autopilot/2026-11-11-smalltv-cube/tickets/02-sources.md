## Что должно заработать

К часам подключаются четыре источника: новые комментарии во всех файлах папки Figma 450204584, новые личные сообщения в Telegram, полоска лимита 5‑часового окна Claude Code со временем сброса и предупреждениями на 80% и 95%, индикатор «Claude ждёт ответа» от хуков Claude Code. `install` ставит автозапуск (launchd, под `caffeinate -i`) и дописывает хуки к существующим в `~/.claude/settings.json`; `uninstall` убирает ровно своё. `telegram-login` — вход в Telegram по коду, который вводит сам пользователь. Источник без ключа в `.env` просто выключен.

## Критерии приёмки

- [ ] Figma: новый комментарий (фейковый API) → уведомление «автор · файл» + текст; уже бывшие при первом запуске и свои — не уведомляют; новый файл в папке подхватывается
- [ ] Telegram: личное сообщение → «имя» + первая строка; группы и каналы игнорируются; фото/голосовое/стикер подписаны словами
- [ ] Лимиты: полоска с процентом и временем сброса на часах; пересечение 80% и 95% → по одной карточке на окно; ошибка чтения → полоска скрыта, в лог причина без токена
- [ ] `python -m cube.hook waiting|answered` с JSON хука на stdin меняет состояние сессии; индикатор горит, пока ждёт хотя бы одна сессия, число видно при >1; записи старше 12 ч игнорируются
- [ ] `install`/`uninstall` в тестах работают на временных путях: существующие хуки (`SessionStart`, `PostToolUse`, `Stop`) сохраняются, свои добавляются и удаляются без следа; plist с RunAtLoad, KeepAlive и `caffeinate -i`
- [ ] Секреты не попадают в лог, вывод, git; `.env.example` содержит `FIGMA_TOKEN`, `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` пустыми
- [ ] `README.md` по-русски: как вписать ключи, войти в Telegram, установить и удалить
