# Спецификация: кубик-экран — часы, погода и уведомления

## Задача
«У меня на столе кубик 240×240 со скучной китайской прошивкой. Хочу, чтобы он показывал красивые часы с погодой, а поверх — то, что мне важно прямо сейчас: комментарий в Figma, сообщение в Telegram, что Claude ждёт моего ответа и сколько осталось лимита».

## Решение
Программа на Mac mini постоянно рисует картинку 240×240 и отправляет её на кубик по Wi‑Fi. Прошивку кубика не меняем: он работает в режиме «фотоальбом» и показывает то, что прислали. В обычном режиме — часы, дата и погода, внизу тонкая полоска лимита Claude, в углу — счётчики непрочитанного. Когда приходит новое, поверх часов выезжает карточка уведомления на 15 секунд, потом остаётся счётчик. Программа запускается сама при входе в систему и не даёт Mac mini засыпать, пока работает.

## Решения по реализации
- **Python 3 + uv**, библиотеки Pillow, httpx, telethon. Почему: на Mac уже есть Python и uv; Pillow рисует кадры без браузера.
- **Прошивка кубика не меняется.** Почему: родная v9.0.51 уже умеет `/doUpload?dir=/image/` (multipart, поле `image`), `/set?img=<путь>`, `/delete?file=<путь>`, `/set?theme=3`, `/set?i_i=…&autoplay=0` — этого хватает, и риска «окирпичить» нет.
- **Анимация — GIF.** Прошивка грузит в `/image/` и GIF; выезд карточки — короткий GIF (≤ ~200 КБ, ≤ ~12 кадров), затем статичный JPEG. Если GIF на кубике не проигрывается — карточка появляется без анимации (это фиксируется как `D##`).
- **Погода** — Open-Meteo, без ключа и денег.
- **Figma** — REST API с личным токеном: список файлов `GET /v1/projects/450204584/files`, комментарии `GET /v1/files/:key/comments`; опрос раз в 2 минуты; свой id — `GET /v1/me`.
- **Telegram** — Telethon от имени пользователя (сессия хранится локально в папке данных программы, в git не попадает).
- **Лимиты Claude** — тот же источник, что у Claude Code: эндпоинт использования подписки с OAuth-токеном Claude Code из Связки ключей macOS; токен только читается, никуда не пишется и не логируется; опрос раз в 5 минут.
- **«Claude ждёт»** — хуки Claude Code (`Stop`, `Notification` → «ждёт»; `UserPromptSubmit` → «ответил»), которые пишут маленький файл состояния по id сессии; программа его читает. Хуки **дописываются** к существующим в `~/.claude/settings.json`, существующие не трогаются; `uninstall` убирает только свои.
- **Данные программы** — `~/Library/Application Support/smalltv-cube/` (состояние, сессия Telegram, лог).
- Установка в систему (launchd, хуки) делается командой `install` — запускается только после «да» пользователя.

## Открытые места
- `FIGMA_TOKEN`, `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` — пользователь вписывает сам в `.env`; пока пусто — соответствующий источник выключен, на часах это не ошибка.
- Вход в Telegram по коду — пользователь, командой `telegram-login`.
