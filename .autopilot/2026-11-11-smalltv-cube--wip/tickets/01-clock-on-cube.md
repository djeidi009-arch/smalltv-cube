## Что должно заработать

`uv run python -m cube run` — и на кубике появляются часы: крупное время мягким шрифтом, дата по-русски, погода в Нячанге, место под полоску лимита Claude и счётчики. Каждую минуту кадр обновляется. Движок уведомлений готов: если источник отдал уведомление, поверх часов выезжает карточка (GIF-анимация), держится 15 с, затем снова часы и счётчик. Кубик выключили — программа ждёт и продолжает. `preview out/` рисует все экраны в PNG (часы без данных, с погодой, со счётчиками, с полоской лимита, с индикатором «Claude ждёт», карточки всех четырёх видов, сводная «ещё N»).

## Критерии приёмки

- [ ] `uv sync` и `uv run pytest -q` проходят; все зависимости из спецификации стоят
- [ ] На живом кубике после `run` виден кадр часов с погодой (проверено: `/filelist?dir=/image/` содержит `cube-*`, кадр показан)
- [ ] Неизменившийся кадр не грузится повторно; свой предыдущий файл удаляется, чужие файлы целы
- [ ] Уведомление из фейкового источника: карточка-GIF → 15 с → часы со счётчиком; 5 уведомлений из одного источника за минуту → не больше 3 карточек + сводная «ещё N»
- [ ] Счётчик гаснет через час без новых
- [ ] Кубик недоступен → `run` не падает, повтор раз в 30 с; погода недоступна → часы рисуются с «—» после 2 часов без данных
- [ ] `preview out/` создаёт PNG всех экранов, перечисленных выше
- [ ] `docs/design.md` описывает решения по дизайну и анимации со ссылками на правила скиллов `impeccable` и `hyperframes-animation`
- [ ] Проверено вручную, проигрывает ли кубик GIF из `/image/`; если нет — карточка показывается статичным JPEG, и это записано в отчёте таска
