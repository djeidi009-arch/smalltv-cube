# Кубик-экран

Mac mini рисует на кубике GeekMagic SmallTV-Ultra лимиты Claude Code, Codex и OpenCode Go, а поверх них — уведомления: новые комментарии в Figma, личные сообщения в Telegram, предупреждения о лимите Claude Code и сигнал «Claude ждёт ответа».

Все команды ниже вводятся в Терминале, в папке проекта:

```
cd ~/Developer/smalltv-cube
```

## 1. Ключи

Скопируйте образец настроек и откройте его в любом текстовом редакторе:

```
cp .env.example .env
open -e .env
```

Вписывайте значение сразу после `=`, без пробелов и кавычек. Файл `.env` остаётся только на вашем Mac и в git не попадает. Пустая строка — значит, этот источник выключен, остальное работает.

**Figma (`FIGMA_TOKEN`)**
1. Откройте figma.com, нажмите на свой аватар → **Settings** → вкладка **Security**.
2. В разделе **Personal access tokens** нажмите **Generate new token**.
3. Дайте имя (например, «кубик»), в правах выберите **Read** для **Current user**, **File content**, **Comments** и **Projects**.
4. Скопируйте токен (он показывается один раз) и вставьте в строку `FIGMA_TOKEN=`.

Программа следит за всеми файлами папки Figma с номером 450204584. Другую папку можно указать в `FIGMA_PROJECT_ID=` — номер виден в адресе страницы папки.

**Telegram (`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`)**
1. Откройте my.telegram.org и войдите по номеру телефона (код придёт в Telegram).
2. Выберите **API development tools**.
3. Заполните форму: App title — например, «Cube», Short name — «cube», платформа — Desktop. Нажмите **Create application**.
4. Скопируйте **App api_id** в `TELEGRAM_API_ID=` и **App api_hash** в `TELEGRAM_API_HASH=`.

Никому не показывайте эти значения.

**Лимит Claude Code** ничего вписывать не нужно: программа берёт вход Claude Code из Связки ключей Mac. Если macOS спросит разрешение для `security`, нажмите «Разрешить всегда».

**Лимит Codex** читается через установленную команду `codex` с активным входом в ChatGPT.
**Лимит OpenCode Go** читается с ключом из `~/.config/opencode/go.key` или переменной `OPENCODE_GO_API_KEY` (её можно задать в `.env`).

На главном экране показан процент использования за 5 часов и неделю. «—» означает, что окно не предусмотрено тарифом или для него пока нет свежих данных. Опрос идёт раз в 5 минут.

## 2. Вход в Telegram (один раз)

```
uv run python -m cube telegram-login
```

Введите номер телефона в международном формате (+7…), затем код, который пришёл в Telegram, и облачный пароль, если он включён. Сессия сохраняется в `~/Library/Application Support/smalltv-cube/` — повторять вход не нужно. На кубике показываются только личные чаты; группы и каналы — нет.

## 3. Проверка

```
uv run python -m cube status
```

Покажет, виден ли кубик и какие источники включены. Посмотреть все экраны без кубика: `uv run python -m cube preview out/` — картинки появятся в папке `out`.

## 4. Автозапуск

```
uv run python -m cube install
```

После этого программа сама стартует при входе в систему, перезапускается, если упала, и не даёт Mac mini засыпать, пока работает. Заодно в настройки Claude Code (`~/.claude/settings.json`) добавляются хуки для сигнала «Claude ждёт ответа»; ваши прежние хуки остаются как были, копия файла до правки — рядом, `settings.json.smalltv-cube.bak`.

Убрать всё:

```
uv run python -m cube uninstall
```

Удаляет автозапуск и только свои хуки — остальные настройки Claude Code не трогаются.

Журнал работы: `~/Library/Application Support/smalltv-cube/cube.log`.
