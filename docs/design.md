# Дизайн экранов кубика

Экран 240×240, IPS, смотрят на него со стола примерно с 1 м. Режим поверхности по скиллу `impeccable` — **Operate**: человек бросает взгляд и сразу понимает время и что нового. Поэтому выразительность — в точности и сдержанности, а не в эффектах. Все значения — в `cube/render.py`, посмотреть все экраны: `uv run python -m cube preview out/`.

## Сцена и цвет

- **Тёмный фон `#0D0E11`.** `impeccable` / craft-floor: «Light or dark picked … from the use scene». Кубик стоит на столе и светит весь день; светлый фон 240×240 в комнате слепит и выглядит как лампа. Чистый чёрный на IPS всё равно серый, поэтому чуть тёплый почти-чёрный.
- **Текст тёплый белый `#F2F0EC`, второстепенный `#9898A0`** — контраст 17:1 и 6.7:1 (craft-floor: текст ≥ 4.5:1, крупный ≥ 3:1). Тело карточки `#CECCC7` на панели `#1D1F25` — 10:1.
- **Цвет только как смысл.** Фиолетовый — Figma, голубой — Telegram, терракотовый — Claude Code, янтарный — «требует внимания» (Claude ждёт, лимит ≥ 80 %), красный — лимит ≥ 95 %. Других акцентов нет.
- Без градиентного текста, стекла, цветных бордеров слева и неоновых свечений (craft-floor → Refuse).

## Шрифт

- **SF Pro Rounded** (`/System/Library/Fonts/SFNSRounded.ttf`, вариативный, есть кириллица) — бриф просит мягкий скруглённый. Веса берутся из оси `wght`: Bold для времени и заголовков, Semibold для чисел, Medium для подписей, Regular для текста карточки.
- **Шкала** (craft-floor: «obvious scale and weight steps»): время 84 px Bold → температура 30 Semibold → заголовок карточки 22 Bold → тело 18 → дата и подписи 17/15 Medium. Минимум 15 px: с метра мельче не читается.
- Время подбирается так, чтобы влезать с полями 12 px; переносы в карточке — по словам, длинное обрезается «…», не вылезает за край (craft-floor: «Run the real copy … fix what overflows»).
- Рисуем в 3× и уменьшаем LANCZOS: Pillow не сглаживает фигуры, иначе края кружков и полосы рваные.

## Часы (обычный режим)

Иерархия сверху вниз — по тому, что ищет взгляд:
1. **Время** — крупно по центру, единственный «герой».
2. **Погода** — нарисованная иконка (не эмодзи: craft-floor запрещает юникод вместо иконок), температура, подпись по-русски. Нет данных дольше 2 часов — одно приглушённое «—».
3. **Верхняя строка** — дата и день недели по-русски слева, счётчики справа (цветная точка источника + число, 99+). Счётчиков нет — строки справа нет.
4. **Лимит Claude** — тонкая полоска 6 px внизу, подпись «Claude 42 %» и «до 18:40». Ниже 80 % она белая и тихая; ≥ 80 % янтарная, ≥ 95 % красная. Нет данных — полоски нет совсем, без заглушек.
5. **«Claude ждёт»** — янтарная плашка вместо даты: самое тёмное-на-светлом пятно на экране, видно боковым зрением. Если ждут несколько сессий — «Claude ждёт · 2».

Сознательно не сделано: карточки-контейнеры на часах (craft-floor: «cards are the lazy container»), подписи-«кикеры» над временем.

## Карточка уведомления

- Панель `#1D1F25`, радиус 20, поля 8 px от края; сверху остаётся строка с маленьким временем и счётчиками — человек не теряет контекст часов.
- Внутри: точка + название источника цветом источника → заголовок (кто / что, до 2 строк) → первая строка текста (до 3 строк).
- Сводная «Ещё N» — та же карточка, тело «Последнее: <имя>».

## Анимация выезда (GIF)

| Параметр | Значение | Откуда |
|---|---|---|
| Движение | карточка выезжает снизу вверх, часы одновременно приподнимаются на 28 px и гаснут | `hyperframes-animation` → `rules/reactive-displacement.md` (вертикальный вариант: «intruder» толкает «victim») |
| Когда уходят часы | к 45 % хода карточки | там же: `VICTIM_FRACTION` 0.4–0.5 — «hit then settle», а не параллельное движение |
| Длительность | 600 мс (10 кадров × 60 мс) | `impeccable` → `reference/animate.md`: 500–800 мс — «deliberately authored focal entrance» |
| Кривая | ease-out expo `1 − 2^(−10t)` ≈ `cubic-bezier(0.16, 1, 0.3, 1)` | `animate.md`: «natural deceleration … do not use bounce or elastic by reflex»; craft-floor: «Exponential ease-out from an already-visible default» |
| Без отскока | `back.out` из reactive-displacement не берём | у карточки на столе нет «веса», отскок на 10 кадрах выглядит как дёрганье |
| Первый кадр | текущие часы как есть | craft-floor: движение начинается из уже видимого состояния |
| Удержание | последний кадр = статичная карточка; GIF без зацикливания, затем через 2 с программа присылает тот же кадр JPEG | спецификация: «короткий GIF, затем статичный JPEG» |

Ограничения GIF: ≤ 12 кадров, ≤ 200 КБ (выходит ~85 КБ). Одно движение на экран — «one authored moment» (craft-floor). Обратной анимации нет: возврат к часам — простая смена кадра, уход быстрее входа (`animate.md`: «Exit faster than entrance»).

## Чего нет и почему

- Иконок источников в виде логотипов — только цветные точки: логотипы на 10 px нечитаемы. Цвет — единственное отличие Figma от Telegram в счётчиках; для личного экрана с двумя источниками это приемлемо.
- Режима reduced motion — у кубика нет такой настройки; анимация одна и короткая.
