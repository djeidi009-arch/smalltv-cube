# Дизайн экранов кубика

Экран 240×240, IPS, смотрят на него со стола примерно с 1 м. Режим поверхности по скиллу `impeccable` — **Operate**: человек бросает взгляд и сразу видит расход лимитов и что нового. Поэтому выразительность — в точности и сдержанности, а не в эффектах. Все значения — в `cube/render.py`, посмотреть все экраны: `uv run python -m cube preview out/`.

## Сцена и цвет

- **Тёмный фон `#0D0E11`.** `impeccable` / craft-floor: «Light or dark picked … from the use scene». Кубик стоит на столе и светит весь день; светлый фон 240×240 в комнате слепит и выглядит как лампа. Чистый чёрный на IPS всё равно серый, поэтому чуть тёплый почти-чёрный.
- **Текст тёплый белый `#F2F0EC`, второстепенный `#9898A0`** — контраст 17:1 и 6.7:1 (craft-floor: текст ≥ 4.5:1, крупный ≥ 3:1). Тело карточки `#CECCC7` на панели `#1D1F25` — 10:1.
- **Цвет только как смысл.** Фиолетовый — Figma, голубой — Telegram, терракотовый — Claude Code, янтарный — «требует внимания» (Claude ждёт, лимит ≥ 80 %), красный — лимит ≥ 95 %. Других акцентов нет.
- Без градиентного текста, стекла, цветных бордеров слева и неоновых свечений (craft-floor → Refuse).

## Шрифт

- **SF Pro Rounded** (`/System/Library/Fonts/SFNSRounded.ttf`, вариативный, есть кириллица) — бриф просит мягкий скруглённый. Веса берутся из оси `wght`: Bold для заголовков, Semibold для чисел, Medium для подписей, Regular для текста карточки.
- Заголовки — 22 px Bold, проценты — 19 px Semibold, названия — 16 px Semibold, подписи — 15 px Medium. В карточках переносим текст по словам и обрезаем длинные строки многоточием.
- Рисуем в 3× и уменьшаем LANCZOS: Pillow не сглаживает фигуры, иначе края кружков и полосы рваные.

## Лимиты (обычный режим)

- Claude, Codex и Open Code идут отдельными строками. Колонки «5 ч» и «7 дн» показывают процент использованного лимита и полоску прогресса. Ниже 80 % — белый, с 80 % — янтарный, с 95 % — красный.
- Прочерк означает, что для окна нет свежих данных. Значения каждого сервиса устаревают независимо через 15 минут.
- Вверху «Лимиты» слева и счётчики справа (цветная точка источника + число, до 99+). При ожидании ответа заголовок сменяется янтарной плашкой «Claude ждёт». Если рядом два длинных счётчика, плашка сокращается до «Ждёт».

## Карточка уведомления

- Панель `#1D1F25`, радиус 20, поля 8 px от края; сверху остаётся строка со счётчиками и сигналом ожидания.
- Внутри: точка + название источника цветом источника → заголовок (кто / что, до 2 строк) → первая строка текста (до 3 строк).
- Сводная «Ещё N» — та же карточка, тело «Последнее: <имя>».

## Анимация выезда (GIF)

| Параметр | Значение | Откуда |
|---|---|---|
| Движение | карточка выезжает снизу вверх, главный экран одновременно приподнимается на 28 px и гаснут | `hyperframes-animation` → `rules/reactive-displacement.md` (вертикальный вариант: «intruder» толкает «victim») |
| Когда уходит главный экран | к 45 % хода карточки | там же: `VICTIM_FRACTION` 0.4–0.5 — «hit then settle», а не параллельное движение |
| Длительность | 600 мс (10 кадров × 60 мс) | `impeccable` → `reference/animate.md`: 500–800 мс — «deliberately authored focal entrance» |
| Кривая | ease-out expo `1 − 2^(−10t)` ≈ `cubic-bezier(0.16, 1, 0.3, 1)` | `animate.md`: «natural deceleration … do not use bounce or elastic by reflex»; craft-floor: «Exponential ease-out from an already-visible default» |
| Без отскока | `back.out` из reactive-displacement не берём | у карточки на столе нет «веса», отскок на 10 кадрах выглядит как дёрганье |
| Первый кадр | текущий экран лимитов | craft-floor: движение начинается из уже видимого состояния |
| Удержание | последний кадр = статичная карточка; GIF без зацикливания, затем через 2 с программа присылает тот же кадр JPEG | спецификация: «короткий GIF, затем статичный JPEG» |

Ограничения GIF: ≤ 12 кадров, ≤ 200 КБ (выходит ~85 КБ). Одно движение на экран — «one authored moment» (craft-floor). Обратной анимации нет: возврат к лимитам — простая смена кадра, уход быстрее входа (`animate.md`: «Exit faster than entrance»).

## Чего нет и почему

- Иконок источников в виде логотипов — только цветные точки: логотипы на 10 px нечитаемы. Цвет — единственное отличие Figma от Telegram в счётчиках; для личного экрана с двумя источниками это приемлемо.
- Режима reduced motion — у кубика нет такой настройки; анимация одна и короткая.
